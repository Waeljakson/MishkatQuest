مضمار المشكاة v1.8.3 — Session Refresh Fix

- حفظ Refresh Token مع Access Token.
- تجديد JWT تلقائياً قبل انتهاء الجلسة.
- إعادة المحاولة مرة واحدة تلقائياً عند JWT expired.
- منع تعارض عدة طلبات تحديث متزامنة عبر refresh lock.
- إصلاح استمرار الدوري وإرسال/قبول التحديات بعد مرور مدة الجلسة.
- رفع إصدار Service Worker لمنع بقاء النسخة القديمة في الكاش.

ملاحظة: مستخدمو النسخة القديمة يحتاجون تسجيل الدخول مرة واحدة بعد التحديث لأن النسخة القديمة لم تكن تحفظ Refresh Token.
