# Mishkat Quest | رحلة المشكاة لإتقان القدرات

تطبيق قدرات لفظية قائم على اللعب لمدارس المشكاة، بهوية جرافيكية حديثة ومسارات تتدرج من السهولة إلى الإتقان.

## حالة v0.2
- تم إنشاء مشروع Supabase مستقل باسم `mishkat-quest`.
- تم تجهيز تسجيل الدخول وإنشاء حساب الطالب عبر Supabase Auth.
- عند التسجيل يُربط الطالب بصفه الدراسي تلقائيًا.
- قاعدة البيانات تدعم: المدارس، المراحل، الصفوف، الفصول، المهارات، العوالم، المهمات، الأسئلة، إجابات الطلاب، XP، العملات، الإتقان، دفتر الأخطاء، الشارات والتحديات اليومية.
- الإجابة الصحيحة والشرح محفوظان في schema خاص ولا يتم إرسالهما للطالب قبل الإجابة.
- الإجابة تُصحح داخل قاعدة البيانات بواسطة RPC آمن `submit_answer` ثم يتم تحديث XP وإحصاءات المهارة ودفتر المراجعة.
- تم إنشاء 7 عوالم و6 مهارات و7 صفوف دراسية.
- تم إدخال أول مهمة فعلية: `جزيرة المختلف` للأول الثانوي، وبداخلها 6 أسئلة موثقة من الحقيبة التأسيسية.
- الواجهات أصبحت مهيأة للبيانات الحقيقية بدل بيانات Demo: Home، الخريطة، المهمة، الملف الشخصي، ولوحة المشرف.

## التشغيل
```bash
npm install
cp .env.example .env
npm run dev
```

ضع إعدادات Supabase في `.env`:
```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_KEY
```

## هيكل الصلاحيات
- `student`: يشاهد محتوى صفه ويحل المهمات ويرى تقدمه.
- `teacher`: يشاهد بيانات الطلاب في المدرسة لأغراض المتابعة.
- `supervisor`: لوحة متابعة وتحليلات.
- `admin`: إدارة المحتوى والصفوف والمهمات.

## ملاحظة أمنية قيد الاعتماد
Supabase Advisor أظهر تنبيهًا لأن جدول مفاتيح الإجابات `private.question_keys` لا يملك RLS، رغم أنه موجود في schema غير عام وتم سحب صلاحيات anon/authenticated منه. قبل الإطلاق النهائي سيُحسم دفاع إضافي بتفعيل RLS عليه بعد اعتماد السياسة المناسبة.
